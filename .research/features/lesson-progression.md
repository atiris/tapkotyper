# Lesson Progression and Adaptive Practice

**Status:** extends spec (spec: parent picks active keys, fallback generator, 5 story phases). **Prio:** P1.

## What
- Built-in default path: home row, then top row, bottom row, shift, digits, diacritics, punctuation. Each story phase maps to a key group so the story and learning move together.
- A key becomes "learned" after steady accuracy; the next key unlocks with a small celebration. Parent can override (spec feature).
- Weak keys (from per-key stats) appear more often, mixed with known keys, so practice stays short and gentle.
- "Quick practice" mode picks 1-2 weak keys for a 3-minute round.
- Skippable intros; lessons short; vary the activity (swatter, rocket, stepping stones already do this).
- Word generator keeps pronounceable pseudo-words when real words do not fit the key set (spec).

## Why
- Gradual unlocking of letters with weak-key weighting and low stress is what users praise most. [src]
- Personalised practice for trouble letters is a valued feature. [src]
- No progression management, low replay value and unskippable songs are frequent complaints. [src]
- Slovak school programs use graded lessons: letters, words, sentences. [src]
- A late game that feels repetitive is a common complaint; keep variety. [src]
