# On-Screen Keyboard with Finger Guide

**Status:** new. **Prio:** P1.

## What
- Always-visible keyboard drawing for the active layout, keys colored by finger (same color per finger, both hands).
- Next key highlighted; wrong key shows a soft hint, not a buzz.
- Hand drawing or glove shapes showing which finger to use; home-row bumps (F, J) marked.
- Three modes set by parent or auto: full guide, letters only fade, hidden (keys masked), so kids stop looking down as they improve.
- Only active keys (from parent settings) are colored; others dimmed, which also teaches the layout slowly.
- Short posture card at session start: feet flat, back straight, wrists floating, eyes on screen. Shown again at breaks.

## Why
- Weak finger guidance is a frequent complaint about children's typing games; teachers must police technique. [src]
- Teacher guides: glancing at keys feels helpful but harms long-term skill; mask keys, use on-screen hand guide as reference. [src]
- Home-row position should be taught from the start. [src: EANI document, https://send.eani.org.uk/sites/default/files/2025-02/Touch%20Typing.docx]
- Hiding-keys evidence is mostly teacher practice; controlled study results not confirmed. [src gap]

## Notes
- Finger colors must also work for colorblind users (add labels or patterns). See accessibility.md.
