# Parent and Teacher Dashboard

**Status:** extends spec (profile setup, active keys, word length, difficulty slider, per-key stats via Tapko). **Prio:** P2.

## What
- Behind a simple parent gate (e.g. a small sum), separate from the child view.
- Per-key heat map (accuracy, speed), top 3 problem keys, trend over weeks.
- Simple presets ("Beginner home row", "Slovak diacritics") plus the granular controls from the spec.
- Toggles: show/hide on-screen keyboard, timers off, diacritic-free words, sound, session limit.
- Printable progress card / certificate; optional milestone certificate (kids like them [bg]).
- Classroom use on a shared computer: switch profile quickly, export all profiles in one file.

## Why
- Parents value progress tracking. [src: Common Sense Media TypingClub parent reviews]
- Teachers want custom lessons and per-student assignment; Typing.com lacks it, TypingClub has it. [src: Common Sense comparison]
- Controls must not become another rigid system; defaults should be good enough to skip it. [src: rigid-scoring complaint]
- Per-key stats are already a spec idea and match Keybr-style insight. [src]
