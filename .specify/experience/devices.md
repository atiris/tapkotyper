# Devices

## What
- **A real keyboard is needed.** A phone or tablet without a mouse, trackpad or keyboard
  (touch only) shows the start page with a card "Pripoj klávesnicu" instead of the players:
  a short explanation (Bluetooth or USB keyboard, then press any key), a status line and
  "Skontrolovať znova". Checking again while still without a keyboard asks to press a key
  and shakes the card gently (no motion with reduced motion). Players, the guest, a new
  player and import stay hidden.
- Pressing any key of a connected keyboard lifts the card at once and for the rest of the
  session (the card has no text field, so an on-screen keyboard cannot lift it).
- Under the card a big orange **"Pre učiteľov"** button with the teacher's own animal (a
  turtle with glasses and a mortar board, not one of the players' animals) opens the teacher
  view; the same turtle greets an empty teacher view.
- Until a key is seen only the start page, the teacher view (also from a result link) and
  help are reachable; any other address goes to the start page. A task link opened then is
  kept and continues once the keyboard is there.
- A computer, or any device with a mouse or trackpad, is never asked for a keyboard.
- **Sound on phones:** sound starts with the first tap. The iPhone's silent switch mutes web
  audio by design.

## Why
- The game teaches typing on a real keyboard; a child on a phone without one should learn
  that before creating a profile, not after a level that cannot be played.
- A teacher scanning results walks the classroom with a phone and needs no keyboard, so the
  way in for the teacher is right on the first screen.
