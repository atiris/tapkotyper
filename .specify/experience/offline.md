# Offline

## What
- Installable PWA. After the first visit, the whole game (including the language files of
  the chosen language) works offline. The version changes whenever any file changes, pictures and music included.
- **New version:** a newer version downloads quietly in the background (an open tab also asks
  every half hour) and waits, never replacing the game in the middle of play. While it waits, a
  red round update button stands at the far right of the corner controls, after help; its
  tooltip says a new version is ready and a click installs it, and the page reloads at once
  (without the leave question). Without the click it takes over once every tab of the game is
  closed. Music is not installed up front: the tracks
  of the worlds played are kept as they play. The teacher's page works offline too: scanning,
  links, history and `.tapko` files need no connection.

- **Install offer:** once, never on the first day: only after the game was opened on three
  different days, and when the browser can install it, the map offers to install it as a web
  app (an icon on the desktop, its own window, reliable without the internet, no whole browser
  needed). Declined or ignored, it is not offered again. The help page's about tab says the game can be
  installed this way.

## Why
- School Wi-Fi is unreliable; offline play also shows that no data leaves the device.
- Asking to install on the first visit is too early; after three days the game has proven itself.
- Without the button a player who keeps a tab open, or only reloads, could run an old version
  for days.
