# Sticky finger

## What
- **Lepkavý prst** / **Sticky finger**: a way of typing where one finger (or a few) "sticks" to its
  home key and holds it down while the other fingers type. It plays in own practice as a fourth way
  of typing next to copy, dictation and memory; which world's level plays it first is not decided
  yet, and the map's dot picture (a small cake with sticky caramel drips) is ready for it.
- **Rounds, in turns:** the right index finger holds J while the left hand types words of only its
  own known keys, then the left index finger holds F while the right hand types. A round lasts a
  fixed share of the run: half of a timed run each, else about 45 seconds of play, and the turns go
  on. A new round starts only between words, so a word is never cut in half.
- **Several held keys:** once the chosen keys allow it (at least 3 keys of an index finger), the
  turns add rounds where a hand holds its other home keys (for example A S D) while its index
  finger alone taps its keys (F R T G V); the same for the right hand. These rounds come after the
  two simple ones.
- **Words of one hand:** only letters typed by that hand alone (no Shift, no accent key of the other
  hand, no space); with too few dictionary words the usual letter groups fill in, as with few keys.
- **The calm rule:** while a held key is up, the run waits. The scene stands still as on a pause,
  without the pause card, and a line over the scene says "Polož prst späť na J a drž ho." / "Put your
  finger back on J and hold it." Keys typed meanwhile count for nothing (no miss, no press). When the
  key is down again, play goes on at once; nothing is lost, no stars are taken, and the waiting
  time does not count as play. Each round starts with the same line until its key is held.
- **What the child sees:** the on-screen keyboard draws a held key as pressed with a soft golden glow;
  a key that must be held but is up blinks gently (no blink with reduced motion). The hands rest a
  golden fingertip on each held key. The held key's own press is never a typed letter.
- **Enough keys:** a run needs at least 4 known letter keys of each hand, F and J among them. With
  fewer the button in the key picker is greyed out and its tooltip says "Najprv si vyber aspoň 4
  klávesy každej ruky." / "First choose at least 4 keys of each hand."; a run asked anyway plays as
  copy typing.
- **The keyboard's limit:** not every keyboard reports several keys held at once (laptop and cheap
  keyboards lose a third or fourth key in some combinations). Before the first run on a device that
  holds two or more keys, a short card asks "Drž A S D a stlač F." and records how many keys arrived
  together. Rounds never hold more keys than the keyboard reports with the typing key (down to one).
  When fewer arrived, the card says "Táto klávesnica nedokáže zachytiť toľko klávesov naraz, tak
  budeš držať menej." and never blames the child. A child who goes on without trying holds one key
  this run and is asked again next time.
- The result belongs to the device, not to a player: it is kept beside the other device-wide
  settings and never travels in a player's export.
- The get-ready card's tip of a sticky run is about holding; the end screen is the usual one.

## Why
- A resting finger cannot drift away: home becomes the place a hand always comes back to, and a
  word cannot be typed with the wrong hand ([research](../../.research/learning/hold-and-reach.md)).
- Waiting instead of punishing keeps it calm: letting go is a reminder, never a mistake.
- Keyboards differ; asking a child to hold keys the keyboard cannot report would look like the
  child's fault, so the game measures it once and asks for less.
