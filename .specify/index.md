# TapkoTyper - specification

WHAT the product does and WHY, per feature, with the best ideas from
[`../.research/`](../.research/index.md) (2026-10-20).

TapkoTyper is a free, peaceful, story-driven touch-typing game for children
and young teens (about 10-15 years). It runs fully in the browser on GitHub Pages, with no backend.

The child plays as an animal character; the game's name for that figure is Ťapko in Slovak
and Tapko in English: "ťapkať" is the patter of small
feet and "tap" is a key press. An earlier working name was dropped for an unwanted slang meaning.

## Product principles

1. **Accuracy before speed.** Clean typing is praised; speed is only shown as a personal trend.
2. **Nothing bad happens to the child.** No lives, no game over, no failing timers, no
   explosions. Obstacles are pushed away, cleared or helped, never destroyed.
3. **No addiction loops.** No streaks, no variable rewards, no leaderboards, no races,
   no chat, no purchases. Sessions are short and end with a calm break.
4. **Private by design.** No accounts, no ads, no tracking, no network calls besides
   loading the app itself. Data stays in the browser and can be exported.
5. **Slovak first.** Slovak QWERTZ layout and diacritics are taught properly; English
   (US QWERTY) is the second full language.
